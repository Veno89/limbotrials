# Browser Demo Release Checklist

## Verified In The Current Build

- [x] Fresh install, strict typecheck, lint, unit tests, and production build pass.
- [x] Menu, settings, character select, run start, reliquary loot ritual/artifact tooltip flow, and immediate boss encounter pass the browser smoke test.
- [x] Old saves receive current settings defaults through versioned loading.
- [x] Production output includes only referenced supplied art.
- [x] Controls are shown on the menu and briefly introduced in the arena.
- [x] The game can reach both game-over and victory scenes.

## Required Before Public Demo

- [ ] Complete several full fifteen-minute balance runs on keyboard.
- [ ] Export and compare balance reports for each full-run test.
- [ ] Verify the latest balance report remains accessible after returning to the menu.
- [ ] Complete one full run centered on each weapon evolution and synergy pair.
- [ ] Verify curse event, blood shrine, reroll, skip, and all three powerups in play.
- [ ] Verify chest timing, artifact tooltips, all three characters, and both character unlocks in play.
- [ ] Test Chrome, Edge, Firefox, and Safari manually.
- [ ] Test common 16:9, ultrawide, and laptop resolutions.
- [ ] Replace or approve all temporary procedural audio.
- [ ] Confirm rights and credits for every shipped art asset and font.
- [ ] Add a short epilepsy/photosensitivity notice if effects warrant it.
- [ ] Add title art, store capsule images, screenshots, and a short trailer.
- [ ] Verify save behavior after a deployed build update.
- [ ] Host a private itch.io build and collect external playtest feedback.

## Later Desktop Release

- [ ] Choose and validate a desktop wrapper.
- [ ] Add controller support and controller glyphs.
- [ ] Add platform-specific quit/fullscreen behavior.
- [ ] Investigate Steamworks only after the browser demo loop is proven.
