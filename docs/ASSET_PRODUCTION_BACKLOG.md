For each delivered visual: update only its explicit import/source row in `src/game/data/assets.ts`, run `npm run validate:content`, inspect it in the F11 Content Lab with applicable origin/attachment/collision guides enabled, then run `npm run verify:release` (which creates a fresh production build before both browser smokes). For each delivered audio file: add its explicit imported source to the existing manifest cue, validate content, manually confirm the WAV metadata below, then audition it in live menus/gameplay through the master plus music/effects volume controls and run `npm run verify:release`. Audio has no visual Content Lab guide pass, and content validation does not parse WAV headers.
